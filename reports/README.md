# Report artifacts

`build_report_ieee.py` creates the submission report from the verified canonical pipeline outputs. It does not refit models or modify research results.

```bash
python scripts/verify_outputs.py
python reports/build_report_ieee.py
```

Outputs:

- `Project2_Team16_Report.docx`: editable source report.
- `Project2_Team16_Report.pdf`: generated by the rendering command below.
- `figures/`: report-specific equation and summary graphics.
- `output_verification.json` and `.csv`: machine-readable pre-report verification.
