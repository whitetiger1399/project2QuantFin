# Report artifacts

`build_report.py` creates the submission report from the recorded pipeline outputs. It does not refit models or modify research results.

```bash
python reports/build_report.py
```

Outputs:

- `Project2_Team16_Report.docx`: editable source report.
- `Project2_Team16_Report.pdf`: generated by the rendering command below.
- `figures/`: report-specific equation and summary graphics.
- `output_verification.json` and `.csv`: machine-readable pre-report verification.

Render and inspect the report with the repository's document tooling:

```bash
python /Users/whitetiger/.codex/plugins/cache/openai-primary-runtime/documents/26.601.10930/skills/documents/render_docx.py reports/Project2_Team16_Report.docx --output_dir reports/_rendered --emit_pdf
cp reports/_rendered/Project2_Team16_Report.pdf reports/Project2_Team16_Report.pdf
```

Edit `assets/authors.json` and rebuild if the team roster changes.
